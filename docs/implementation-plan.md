# Iterative implementation plan

The initial repository contained only README and LICENSE. This increment establishes runnable code across the six phases, with explicit remaining production requirements.

1. **Foundation:** npm workspaces, strict TypeScript, Vite/React, Express, environment validation, Mongoose models, Argon2id login, transactional session rotation, CSRF, invitation/reset tokens, MFA enrollment UI and replay checks, responsive shell and tested account-isolated client cache. Remaining: email delivery, complete security-event auditing, MFA recovery/enforcement and independent security review.
2. **People and access:** built-in role seed, resource scope checks, employee create/edit/search/pagination/history and lifecycle transition checks, organization reference data, encrypted identifiers, salary histories, role creation, user invitation/access and manual recovery APIs/UI. Remaining: full lifecycle policy, document storage, controlled exports/imports, identifier UI, organization edit/archive coverage and role editing.
3. **Time and leave:** clock in/out, UTC timestamps, Manila day conversion, atomic CSV import, schedules, holiday records, adjustment requests/approval UI, paid balances and ledger with adjustment UI, leave and overtime decisions, explicit locked-period policy port. Remaining: schedule-based tardiness/undertime/night differential, accrual jobs, calendar/history, overlap checks and input-write/finalization race coverage.
4. **Financial preview:** exact integer arithmetic, bracket validation, earnings classifications, effective salary lookup, policy upload/versioning, snapshot calculation and exception reporting. Remaining: comprehensive statutory methods, approved policy review, official fixtures, salary/time segmentation, year-end annualization, 13th month.
5. **Payroll lifecycle:** revision-checked review/approval/rejection/finalization code, immutable snapshots through API, independent approval, finalization gate, payslip PDF endpoint and release, loans/repayments, scoped employee access. Synthetic lifecycle tests verify finalization/payment primitives; browser tests verify the real finalization gate. Remaining: full reversal/correction workflow, release transactions, comprehensive financial/input revalidation and complete self-service screens.
6. **Operations:** payment batch approval/single-use export/reconciliation, CSV payroll register, audit list, notifications, Docker/replica-set setup, CI and deployment instructions. Remaining: all requested reports/formats, configurable bank templates, audit DB-level protections, restore drill, monitoring, load/security testing.

Run checks after every increment. Do not mark a phase production-complete until its outstanding items, positive and negative tests, security review and applicable payroll/legal review are closed. See TODO.md for the release checklist.
